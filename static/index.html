Help & Documentation

                    
                

                

                    
Getting Started

                    
This tool helps you manage Azure Cognitive Search index and skillset configurations through a simple web interface.

                    
                    
Managing Index Fields

                    
    
                        
  • Add Field: Click "Add Field" to create new searchable fields
    • 
                        
  • Field Types: Choose from various Azure field types (String, Int32, Boolean, etc.)
    • 
                        
  • Properties: Set searchable, filterable, sortable, and facetable properties
    • 
                        
  • Key Field: Mark one field as the unique key
    • 
                    

                    
                    
Managing Skillset Skills

                    
    
                        
  • Add Skill: Click "Add Skill" to add processing skills
    • 
                        
  • Skill Types: Choose from entity recognition, text splitting, language detection, etc.
    • 
                        
  • Context: Set the document context for skill processing
    • 
                    

                    
                    
File Operations

                    
    
                        
  • Download: Export current configurations as JSON files
    • 
                        
  • Upload: Replace configurations by uploading new JSON files
    • 
                        
  • JSON Preview: View formatted JSON in real-time
    •
